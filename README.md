## Projects
 **Intelligent PDF QA Agent**
 
 I created a system that processes PDF documents and answers user questions based on the content of the document. It uses:
Text chunking
Embedding generation with sentence-transformers (MiniLM)
Storage in a FAISS database
Context retrieval and answers via a pre-trained LLM (FlanT5) using Hugging Face Transformers
